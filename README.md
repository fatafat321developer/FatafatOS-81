## What is FatafatOS 81?

FatafatOS 81 Tiranga Edition is a 50MB lightweight operating system made in India for low-end laptops and computers. It is built entirely from scratch.

Built on: Android phone using Termux and NASM Assembly  
Runs on: PC, Laptop, VirtualBox, Limbo Emulator  
Base: Pure Assembly (boot.asm) + C (kernel.c, kernel.h, linker.ld)
