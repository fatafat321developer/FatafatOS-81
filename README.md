# FatafatOS 81 - Light & Fast Made in India OS 🇮🇳

FatafatOS is a 50MB lightweight operating system built from scratch in Telangana, India.
Built entirely on Android phone using Termux & NASM Assembly.

## Features
- 50MB ISO, boots in 2 seconds
- 320x200 Tiranga Desktop UI
- Own file formats: .fata, .fatatheme, .fsw, .fsl
- Shell commands: help, desktop, clear, about
- Made in India - 100% Indian OS
